Main Cloud properties

1. On demand service which is where a consumer can make a request and instantly get a respond
2. Pooling of resources, shared between consumers in relation with demand
3. Usage, Usage is is managed at all time and can be changed depending on demand

Types of Cloud services

(IAAS) Internet as a service, Allows on demand services, such as storage like google cloud, and iCloud

(PAAS) Platform as a service, Controls different resources for things like testing and managing cloud applications.

(SAAS) Software as a service, An application that is a service and customers can use. Microsoft 365, Google workspace, Zoom.
