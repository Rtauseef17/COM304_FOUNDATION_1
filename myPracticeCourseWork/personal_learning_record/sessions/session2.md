A server computer is quite differnet to a personal machine. A server computer is running 24/7 and may run at a tempreture between 30-40 degrees needing it to have higher/more efficient cooling.

A cache is a temporary high speed storage area that saves frequently accessed data to make future requests faster. It acts as an intermediatary for the CPU and RAM and can be found in different forms.

ZIP files are multiple files that are compressed that are compressed into one file which improves efficiency
