# Council Proposal 1

## Explanation of this proposal
*What do you think this proposal might mean? How might it be implemented?*

Based on my understanding of operating systems and cloud infrastructure, I propose transitioning from individually assigned office PCs to a centralised hot-desk environment. By deploying lightweight workstations, staff can authenticate into shared devices while maintaining personalised access to cloud-hosted profiles and applications. This approach increases hardware utilisation, reduces maintenance overhead, and supports flexible working patterns. My experience with system configuration and user management in Linux, as well as cloud concepts introduced in Session 10, provides me with the technical foundation to design and evaluate such a modern workspace solution.

## Technologies and research relevant to this proposal
*Which class sessions and personal research refers to technology in this proposal. Link to examples.*

Session 1 (Raspberry Pi & Linux Basics): Helped me understand operating systems, user logins, and system configuration—skills directly transferable to managing shared hot-desk workstations.

Session 7 (Operating System Structure & Package Management): Gave me insight into system imaging, updates, and centralised administration, which are essential for standardised hot-desk devices.

Session 9 (Azure Cloud): Introduced cloud-hosted profiles and virtual desktops, a core component of modern hot-desking environment
