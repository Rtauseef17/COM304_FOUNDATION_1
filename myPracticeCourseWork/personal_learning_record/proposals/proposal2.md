# Council Proposal 1

## Explanation of this proposal
*What do you think this proposal might mean? How might it be implemented?*

Informed by the session on Azure cloud computing, I propose gradually migrating the council’s on-premises server software into cloud-based services. Cloud platforms offer scalability, improved resilience, automated backups, and reduced physical infrastructure costs. By leveraging virtual machines and managed services in the cloud, applications can be modernised without sacrificing performance or security. The hands on work I completed with virtual machines in Session 10 has given me a practical insight into securing, and maintaining cloud environments, making this proposal both feasible and technically justified.
